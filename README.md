This repository contains three Java programming assignments related to comparing arrays. Each task is implemented in a separate package (h1, h2, h3) and the required methods are written directly inside the respective H*_main classes as specified.

The first assignment implements isMirrorArray, which returns true if two arrays are mirror images of each other, meaning one array is the exact reverse order of the other. The second assignment implements compareArrays, which returns true only if two arrays contain exactly the same elements in the same order and with the same frequency.

The third assignment implements compareArraysVal, which checks whether two arrays contain the same values with the same frequencies, regardless of their order. All methods strictly follow the required method signatures and return types and are designed to work according to the assumptions described in the tasks.
